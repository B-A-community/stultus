# Stultus · Graphite

Первый дизайн-вариант по DESIGN-BRIEF.md: графитовая основа, тёплая типографика, мягкий лаймовый акцент, линейная история действий и отдельные карточки решения.

## Посмотреть

Открыть `showcase.html` в браузере. Вверху переключаются ширина 380 / 700 / 1200 px и девять состояний. `preview.html` открывает только окно плагина и подстраивается под размер браузера. Всё работает офлайн.

В макете работают раскрытие кода, выбор провайдера и модели, контекст сцены, отправка демонстрационного сообщения, остановка, вопрос, разрешение/отказ в снимке, новый разговор и настройки. Сцена, ответы, стоимость и соединение демонстрационные. Реальные запросы не отправляются, настройки не записываются.

## Файлы для внедрения

- `app.css` — полный набор стилей, состояния и адаптивная компоновка.
- `index.html` — разметка для плагина с сохранёнными id и классами DOM-контракта.
- `ui.js` — блокировка ввода при занятости/отсутствии связи, стартовые подсказки, клавиатурное управление настройками.
- `app.js` — копия существующей логики плагина из исходного проекта; не изменялась.
- `stultus.svg`, `empty.svg` — локальный знак и графика стартового экрана.
- `stultus-16.png`, `stultus-24.png`, `stultus-32.png` — иконки панели SketchUp с прозрачным фоном.
- `demo.js`, `preview.html`, `showcase.html`, `pergola.svg` — только для демонстрации дизайна, не для установки в плагин.

Для интеграции заменить разметку и стили в `src/stultus/html`, добавить `ui.js`, `stultus.svg`, `empty.svg` в ту же папку. Рабочий `app.js` брать из актуального проекта. Иконки положить в папку иконок и указать их в существующем объявлении панели инструментов. Исходный репозиторий и установленный плагин в рамках этого варианта не менялись.

## Цветовые токены

| Токен | Назначение |
|---|---|
| `--bg` | Основное поле окна |
| `--surface`, `--raised` | Задача пользователя, элементы ввода, код |
| `--line` | Разделители |
| `--text`, `--muted`, `--quiet` | Основной, вторичный и вспомогательный текст |
| `--accent`, `--accent-ink` | Основное действие и текст на акцентном фоне |
| `--ok`, `--warning`, `--danger` | Успех, ожидание и ошибка |
| `--column` | Максимальная ширина основной ленты |

Шрифты системные: Segoe UI и Consolas/Cascadia Mono. Светлая тема в этот вариант не включена.

## Проверка

Проверены в Chromium: три ширины, девять состояний при 380×460, отсутствие горизонтального переполнения страницы, положение поля ввода, вопрос, снимок, отправка, остановка, закрытие настроек через Escape. В папке находятся PNG основных размеров и ключевых состояний.

В реальном SketchUp 2024 и с рабочим gateway вариант пока не проверен. Перед выпуском нужна проверка подключения, стриминга, Ruby-вызовов, снимков и восстановления истории в SketchUp.
