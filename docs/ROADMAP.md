# План и «долгий ящик»

## Ближайшее

- Вставка Ctrl+V из буфера проверить руками в SketchUp (программно
  проверены скрепка и путь до модели).
- Библиотека приёмов: экспорт/импорт JSON, теги, поиск.

## Идеи (отобраны 2026-09-19)

- **Ограничитель размера операции.** Скрипт, создающий больше N тысяч рёбер
  или трогающий больше N объектов за раз, дробится автоматически: модель
  получает «сделано 40 %, продолжай со смещения …». Тяжёлые построения
  перестают вешать SketchUp на минуты. Стабильность.
- **Кэш снимка сцены.** Снимок собирается инкрементально по наблюдателям
  и отдаётся мгновенно, модели уходит только разница с прошлого хода.
  Ход короче, токенов меньше. Скорость.
- **Параллельные генерации большого кадра.** Две-три плитки одновременно:
  4K с пяти минут до двух, 8K с пятнадцати до шести. Учесть память
  виртуалки (2–4 ГБ) и лимиты подписки. Скорость.
- **Стандарты бюро как правила.** Файл на сервере: имена слоёв, толщины
  стен, высоты этажей, материалы по назначению. Модель обязана соблюдать,
  окно подсвечивает нарушения. Вырастает из копилки приёмов.
  Эксклюзивность.
- **Сравнение вариантов.** «Дай три варианта входной группы»: модель строит
  три группы рядом со смещением, окно показывает три снимка с кнопками
  «оставить этот», остальные удаляются одним Undo. Эксклюзивность.

### Этажность зданий: чем заменить платный 2GIS (проверено 2026-09-22)

Массинг берёт этажность из OpenStreetMap; там, где её нет, высота
подбирается по соседним домам того же типа. Бесплатного источника
этажности по запросу не нашлось — проверено вживую:

- **`data.mos.ru`** — ключ получен и работает, но этажности в портале нет.
  Просканированы поля всех 1246 наборов каталога: «Этажность» есть только
  у шести, самый крупный «Объекты капитального строительства» — 1817 строк
  и лишь стройки. Городского реестра домов с этажностью на портале нет.
  Ключ лежит в `build/mos-api-key.txt` (в репозиторий не попадает).
- **НСПД Росреестра** — сертификат не из общего хранилища, поиск по адресу
  отвечает «объектов нет», слой капитального строительства запрещает наш адрес.
- **Публичная кадастровая карта** — соединение не устанавливается ни с
  российского адреса, ни с зарубежного.
- **Реформа ЖКХ** — выгрузки бесплатные, но это архивы по всей стране и
  только жилой фонд. ГИС ЖКХ простого интерфейса не отдаёт.
- **OSM Buildings** — анонимный доступ закрыт. **Overture Maps** — публичного
  интерфейса нет, только файлы parquet в облаке.
- **2GIS** — умеет всё сразу, но доступ к API платный и дорогой. Код
  поддержки ключа в массинге остался, включается переменной `DGIS_KEY`.

### Слои Москвы поверх массинга (2026-09-22)

Ключ `data.mos.ru` пригодится не для высот, а для контекста, которого нет
в OpenStreetMap: «Объекты культурного наследия федерального значения»
(набор 62302, с адресами и геометрией), «Объекты археологического
наследия» (64026), «Границы зон охраны объектов культурного наследия»
(613). В массинге это отдельный слой: памятник подсвечивается своим
материалом, зона охраны ложится плоским контуром на землю — архитектор
сразу видит, где ограничения по высоте. Работы на день-два.

## Долгий ящик

- **Общая память бюро**: заметки о проектах, договорённости по слоям и
  материалам; инструмент «вспомнить», пополнение фразой «запомни». На
  gateway, без веса в плагине.
- Автоматическая резервная копия модели перед первым изменением хода.
- Инструменты `set_material` / `set_layer` вместо кода (простым языком:
  модель сейчас красит и раскладывает по слоям через Ruby-скрипт; отдельный
  инструмент «назначь материал X объектам Y» надёжнее и понятнее в ленте).
- V-Ray: камера, окружение, свет через проверенные вызовы
  (docs/KNOWLEDGE-VRAY.md, раздел «не проверено записью»).
- **Обновление плагина без переустановки** (2026-09-17). Окно грузится
  с gateway (`set_url` на `https://сервер/ui/` вместо `index.html` из папки
  плагина): интерфейс обновляется вместе с сервером, у сотрудников ничего
  не делают; локальная копия остаётся запасной. Для Ruby-части: gateway
  сообщает в приветствии свою и минимальную версию плагина, окно показывает
  «доступна версия …», по клику скачивает `.rbz` с сервера и ставит через
  `Sketchup.install_from_archive` с перезапуском SketchUp. Горячую
  перезагрузку Ruby не делать: дублируются наблюдатели и меню.
- **Пульт главного архитектора** (2026-09-17). Страница на gateway с
  плиткой на каждое подключённое окно: файл, выделение, живой кадр
  вьюпорта раз в 1–2 с (плагин шлёт кадр только при смене камеры или
  модели, снимок на главном потоке 50–100 мс). Вмешательство по ступеням:
  сообщение в чужой чат с пометкой «от главного архитектора», задание
  нейросети в чужом окне, прямой `execute_ruby`. Не удалённый рабочий стол:
  мышью в чужом SketchUp водить нельзя. Индикатор «за окном наблюдают»
  обязателен; через интернет к VPS кадры реже. Канал сервер→окно и вызовы
  инструментов уже есть, объём 3–4 дня.
- **Лаунчер плагинов бюро** (2026-09-22). Панель «Плагины» в окне: каталог
  с gateway (имя, версия, описание, ссылка на `.rbz`, хеш), кнопки
  «Установить», «Обновить» (если версия на сервере новее установленной),
  «Удалить». Установка штатным `Sketchup.install_from_archive` с
  подтверждением SketchUp; удаление — снять галочку загрузки у расширения,
  удалить папку и загрузчик из папки плагинов, честно предупредить «исчезнет
  после перезапуска SketchUp» (штатного вызова удаления в API нет). Хеш
  проверять до установки; при политике загрузки «только подписанные»
  неподписанные плагины бюро не загрузятся. Тем же путём — обновление самого
  Stultus. Объём два-три дня с каталогом.
